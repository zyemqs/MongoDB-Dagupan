STEP 02 Array Destructuring

Extract values from arrays using bracket syntax. Supports skipping elements with commas and using rest syntax to collect remaining items.

// Array Destructuring const colors = ["red", "green", "blue", "yellow"]; // Basic extraction const [first, second] = colors; // Skip elements using commas const [, , third] = colors; // Rest syntax to collect remaining const [head, ...rest] = colors; // Swap variables let a = 1, b = 2; [a, b] = [b, a];
// Console Output
first: "red" // index 0
second: "green" // index 1
third: "blue" // skipped 0 and 1
head: "red"   rest: ["green","blue","yellow"]
a: 2 b: 1 // swapped
STEP 03 Object Destructuring

Extract properties from objects using curly brace syntax. Variable names must match property keys (unless renamed — see Step 4).

// Object Destructuring const student = { name: "Maria", age: 21, course: "Computer Science", year: 3 }; // Extract multiple properties at once const { name, age, course } = student; // Rest syntax for remaining properties const { name: sName, ...details } = student;
// Console Output
name: "Maria"
age: 21
course: "Computer Science"
details: { age: 21, course: "Computer Science", year: 3 }
STEP 04 Advanced Destructuring

Combine nested destructuring (objects within objects/arrays), default values (used when property is undefined), and variable renaming (colon syntax) for complex data handling.

// Nested + Defaults + Renaming const employee = { id: 101, fullName: "Juan dela Cruz", address: { city: "Quezon City", country: "Philippines" }, scores: [95, 87, 91] }; // Nested destructuring const { address: { city, country } } = employee; // Rename: fullName → name; default for missing prop const { fullName: name, department = "General" } = employee; // Nested array destructuring const { scores: [top] } = employee;
// Console Output
city: "Quezon City"   country: "Philippines"
name: "Juan dela Cruz" // renamed from fullName
department: "General" // default (not in object)
top score: 95 // first element of scores array
STEP 05 Destructuring in Function Parameters

Destructure directly inside function signatures to avoid repetitive property access. Works for both array and object parameters, and supports defaults inline.

// Function Parameter Destructuring // Object destructuring in params function greetStudent({ name, course = "Undeclared" }) { console.log(`Hello, ${name}! Course: ${course}`); } // Array destructuring in params function showTopTwo([first, second]) { console.log(`1st: ${first}, 2nd: ${second}`); } // Nested destructuring in params function getCity({ address: { city } }) { console.log(`City: ${city}`); } greetStudent({ name: "Ana", course: "IT" }); showTopTwo([98, 95, 90]); getCity(employee);
// Console Output
Hello, Ana! Course: IT
1st: 98, 2nd: 95
City: Quezon City
